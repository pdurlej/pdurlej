## Current Thesis

You can't make stochastic models deterministic by wishing harder.

But you can shape the riverbanks:

- context,
- tools,
- tests,
- static analysis,
- second-opinion reviews,
- project memory,
- clear guardrails,
- and boring evidence trails.

That is the work: deterministic outcomes in a nondeterministic world.

Before AI, words were mostly words.
After AI, words increasingly become code.

Welcome to 2026.
